内置存档管理器

每次保存时，编辑器都会先自动备份文件。可以在挑战首领或做出重大选择之前建立命名备份，一键还原任意备份，比较两个备份，或把存档放到一边，开始新游戏并稍后再回来。备份保存在你电脑上存档的旁边。

存档管理器的工作方式
不想运行程序？浏览器版是同一个编辑器，在网页中于你自己的电脑上运行：存档不会被上传。它无法在你的文件夹中查找存档，也不能替你备份，所以请自己打开文件并保留一份副本；保存时会下载编辑后的文件（Chrome 和 Edge 还可以保存回同一个文件，并先在浏览器中保留原文件）。首次访问之后，它在没有网络连接时也能打开。

什么是存档编辑器？

存档编辑器会打开游戏保存时写出的文件，让你修改其中存储的内容：金钱、经验、物品、属性、解锁项。游戏的存档格式多种多样，往往经过压缩、加密或带有校验和保护，所以每款游戏都需要单独处理。Universal Save Editor 用一个程序为 590+（593）款游戏完成这些工作，并按游戏期望的方式把文件写回去。

如何编辑存档文件

  1. 下载编辑器，或打开浏览器版。
  2. 在下载版应用中，选择查找我的游戏存档并选中你的游戏。在浏览器中，请自己打开存档文件。
  3. 修改你想改的内容。523 款游戏会打开专为其设计的界面，每个数值都有名称；其他存档则显示为数值列表，或通过数值搜索来查找。
  4. 保存。下载版应用会先备份旧文件，再把新文件读回来检查，确认无误后才替换；浏览器版会下载编辑后的文件（在 Chrome 和 Edge 中也可以写回同一个文件），所以请保留一份原文件。然后在游戏中读取这个存档。

关于编辑存档的常见问题

编辑存档文件安全吗？

下载版应用会在每次保存前备份旧文件，再把新文件读回来检查，确认无误后才替换。如果游戏不接受某项修改，可在备份中还原。使用浏览器版时请自行保留原文件（在 Chrome 和 Edge 中，打开以保存回原文件也会在第一次保存前在浏览器中保留一份）。

需要上传我的存档吗？

不需要。编辑器是运行在你自己电脑上的程序，可离线使用。浏览器版同样在你的电脑上、在网页内运行，绝不会上传存档。

支持哪些游戏？

590+（593）款游戏列在英文首页上，每款都有一个页面说明可以修改什么以及存档在哪里。未列出的游戏的存档通常也能打开：格式常见时显示为带名称的数值，否则可用数值搜索。

能在 Steam Deck、Linux 和 Mac 上使用吗？

可以。提供 Windows、Linux 和 macOS 的下载。在 Linux 和 Steam Deck 上，查找我的游戏存档还会查找 Steam Play 存放 Windows 游戏存档的 Proton 和 Wine 前缀目录。

编辑过的存档能用于在线游戏吗？

编辑过的存档仅限单人游戏使用。请勿在在线或多人模式中使用，否则可能违反规则或导致账号被标记。

需要付费吗？

不需要。它免费，而且永远免费：没有广告，无需账号，没有限制。代码以 GPL-3.0 开源。
