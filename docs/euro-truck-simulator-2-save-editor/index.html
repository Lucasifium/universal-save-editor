What you can edit

Driver: money, loan limit, experience, the five skills and ADR classes; every vehicle's fuel, odometer and wear, with buttons to max skills, fill every tank and repair everything. Packed saves are unpacked and packed again with their checksum.

Where Euro Truck Simulator 2 keeps its saves

Folder: Documents\Euro Truck Simulator 2\profiles\<profile>\save\<save name>

Files: game.sii (a packed ScsC file or plain text)

You don't need to find it yourself: choose Find my game's saves in the editor, pick Euro Truck Simulator 2, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Euro Truck Simulator 2 save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Find my game's saves, pick Euro Truck Simulator 2 and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Questions about Euro Truck Simulator 2 saves

Where is the Euro Truck Simulator 2 save file?

Usually in Documents\Euro Truck Simulator 2\profiles\<profile>\save\<save name>, in files named game.sii (a packed ScsC file or plain text). The downloaded editor finds it for you: choose Find my game's saves and pick Euro Truck Simulator 2.

Will Euro Truck Simulator 2 still load an edited save?

The editor writes the save back in the same format the game uses and reads the new file back to check it before replacing anything. The original is backed up first, so if anything looks wrong in the game, restore it from Backups.

Can I edit Euro Truck Simulator 2 saves on Steam Deck or Linux?

Yes. There's a Linux build, and Find my game's saves also looks inside the Proton and Wine prefixes where Steam Play keeps Windows games' saves.

Can I edit my Euro Truck Simulator 2 save in the browser?

Yes. The browser version runs on your own computer and never uploads the save. Open the file yourself and keep a copy, because saving downloads the edited file instead of backing up the old one.

Is it safe to use with online play?

Edited saves are for single-player play. Don't use them in online or multiplayer modes, where they can break rules or get an account flagged.

Does it cost anything?

No. It's free and always will be: no ads, no account and no limits. The code is open source under the GPL-3.0.
