What you can edit

Health, food, XP, game mode, world settings, inventory and ender chest, with a Max crafting materials button that fills the ingots, raw ores, gems, string, leather and other materials already carried to 64, leaving ender pearls, eyes of ender and other progression items alone. The button hasn't been tried in the game yet.

Where Minecraft (Java Edition) keeps its saves

Folder: %APPDATA%\.minecraft\saves\<world>

Files: level.dat (and region\*.mca)

You don't need to find it yourself: choose Select game in the editor, pick Minecraft (Java Edition), and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Minecraft (Java Edition) save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Minecraft (Java Edition) and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
