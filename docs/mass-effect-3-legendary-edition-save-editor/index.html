What you can edit

Shepard: level, experience, talent points, difficulty; credits, medi-gel, element zero, iridium, palladium, platinum, probes, fuel, grenades; power ranks; spare ammo; each squad member's level, talent points and powers. The save's checksum is updated

Where Mass Effect Legendary Edition (ME3) keeps its saves

Folder: Documents\BioWare\Mass Effect Legendary Edition\Save\ME3\<career folder>

Files: Save_0001.pcsav, AutoSave.pcsav, QuickSave.pcsav

You don't need to find it yourself: choose Select game in the editor, pick Mass Effect Legendary Edition (ME3), and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Mass Effect Legendary Edition (ME3) save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Mass Effect Legendary Edition (ME3) and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
