What you can edit

Colony: every duplicant's attribute levels and experience, total experience and learned skills; a Map of every asteroid and rocket interior (elements, temperature and germ views; paint elements with mass and temperature, dig out to vacuum, set temperature or mass, clear germs, reveal the fog; geysers, teleporters, Gravitas finds, story traits, artifacts and the Printing Pod as toggleable markers); Worlds & rockets: names, discovered, sunlight and cosmic radiation, and what's on the star map

Where Oxygen Not Included keeps its saves

Folder: Documents\Klei\OxygenNotIncluded\cloud_save_files\<Steam id>\<colony> (or save_files\<colony>)

Files: <colony>.sav

You don't need to find it yourself: choose Select game in the editor, pick Oxygen Not Included, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Oxygen Not Included save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Oxygen Not Included and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
