Where Like a Dragon: Pirate Yakuza in Hawaii keeps its saves

Folder: %APPDATA%\Sega\LikeADragonPirates\Steam\<Steam id>

Files: data.sav (MessagePack inside)

You don't need to find it yourself: choose Select game in the editor, pick Like a Dragon: Pirate Yakuza in Hawaii, and it lists the saves it finds.

How to edit your Like a Dragon: Pirate Yakuza in Hawaii save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Like a Dragon: Pirate Yakuza in Hawaii and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.
