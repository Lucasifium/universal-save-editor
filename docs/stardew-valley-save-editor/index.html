What you can edit

Gold, Qi Gems, casino coins, Golden Walnuts; health and energy; the six skills (level and XP, with the XP the next level needs); farm details

Where Stardew Valley keeps its saves

Folder: %APPDATA%\StardewValley\Saves\<Farm>_<id>

Files: <Farm>_<id> (no extension)

You don't need to find it yourself: choose Select game in the editor, pick Stardew Valley, and it lists the saves it finds.

How to edit your Stardew Valley save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Stardew Valley and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
