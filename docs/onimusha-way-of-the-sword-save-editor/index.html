Where Onimusha: Way of the Sword keeps its saves

Folder: Steam\userdata\<account>\2638890\remote\win64_save

Files: data001Slot.bin

You don't need to find it yourself: choose Select game in the editor, pick Onimusha: Way of the Sword, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Onimusha: Way of the Sword save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Onimusha: Way of the Sword and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.
