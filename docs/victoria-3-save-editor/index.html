What you can edit

Binary saves (the game's default, and ironman) are edited in place and stay binary; the game doesn't publish its field names, so most fields show as numbers unless you add a token file. Debug-mode text saves open with every name

Where Victoria 3 keeps its saves

Folder: Documents\Paradox Interactive\Victoria 3\save games

Files: *.v3

You don't need to find it yourself: choose Find my game's saves in the editor, pick Victoria 3, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Victoria 3 save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Find my game's saves, pick Victoria 3 and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Questions about Victoria 3 saves

Where is the Victoria 3 save file?

Usually in Documents\Paradox Interactive\Victoria 3\save games, in files named *.v3. The downloaded editor finds it for you: choose Find my game's saves and pick Victoria 3.

Will Victoria 3 still load an edited save?

The editor writes the save back in the same format the game uses and reads the new file back to check it before replacing anything. The original is backed up first, so if anything looks wrong in the game, restore it from Backups.

Can I edit Victoria 3 saves on Steam Deck or Linux?

Yes. There's a Linux build, and Find my game's saves also looks inside the Proton and Wine prefixes where Steam Play keeps Windows games' saves.

Can I edit my Victoria 3 save in the browser?

Yes. The browser version runs on your own computer and never uploads the save. Open the file yourself and keep a copy, because saving downloads the edited file instead of backing up the old one.

Is it safe to use with online play?

Edited saves are for single-player play. Don't use them in online or multiplayer modes, where they can break rules or get an account flagged.

Does it cost anything?

No. It's free and always will be: no ads, no account and no limits. The code is open source under the GPL-3.0.
