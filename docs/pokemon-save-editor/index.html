How to edit your Pokémon save

  1. Get the save file. On an emulator, it's the game's save file (often .sav). On a console, back the save up to your computer with a save manager tool first.
  2. Keep a copy of the original somewhere safe.
  3. Download Universal Save Editor, or use it in your browser, and open the save (or drag it onto the window).
  4. Change what you want, then Save. The editor checks the new file and, in the downloaded app, backs up the old one first.
  5. Put the edited save back where it came from.

Questions

Which games does it open?

The mainline games listed above. It recognises the game from the save itself, so you don't pick it from a list.

Will the game still accept the save?

The editor rewrites the checksums and encryption the games use, and keeps linked values in step: a Pokémon's level sets its experience and stats. Always keep a copy of the original anyway.

Can I use edited Pokémon online?

No. Edited saves are for single-player play. Don't trade or battle online with edited Pokémon.

Is it free?

Yes, and it always will be: no ads, no account, no upload, no limits. The code is open source under the GPL-3.0.
