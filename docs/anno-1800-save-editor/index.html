What you can edit

Company:

  • Your coins (the load screen's total is changed with them) and the rest of your company's storage by GUID
  • The .a7s archive and its 100+ MB game data are unpacked and packed again for you (checked on a public save, not yet tried in the game)

Where Anno 1800 keeps its saves

Folder: Documents\Anno 1800\accounts\<account id>\<profile>\savegame

Files: <name>.a7s

You don't need to find it yourself: choose Find my game's saves in the editor, pick Anno 1800, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Anno 1800 save

  1. Download Universal Save Editor for Windows, macOS or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file (Chrome and Edge can save back to the same file).
  2. Close the game, so it doesn't write over your changes.
  3. Choose Find my game's saves, pick Anno 1800 and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Questions about Anno 1800 saves

Where is the Anno 1800 save file?

Usually in Documents\Anno 1800\accounts\<account id>\<profile>\savegame, in files named <name>.a7s. The downloaded editor finds it for you: choose Find my game's saves and pick Anno 1800.

Will Anno 1800 still load an edited save?

The editor reads and writes this save correctly on the test saves it was checked with, but loading an edited save in the game itself hasn't been tried yet. The original is backed up before every save, so if the game doesn't accept the edit, restore it from Backups.

Can I edit Anno 1800 saves on Steam Deck or Linux?

Yes. There's a Linux build, and Find my game's saves also looks inside the Proton and Wine prefixes where Steam Play keeps Windows games' saves.

Can I edit my Anno 1800 save in the browser?

Yes. The browser version runs on your own computer and never uploads the save. Open the file yourself and keep a copy, because saving downloads the edited file instead of backing up the old one. In Chrome and Edge it can also save back to the same file, keeping the original in the browser first.

Is it safe to use with online play?

Edited saves are for single-player play. Don't use them in online or multiplayer modes, where they can break rules or get an account flagged.

Does it cost anything?

No. It's free and always will be: no ads, no account and no limits. The code is open source under the GPL-3.0.
