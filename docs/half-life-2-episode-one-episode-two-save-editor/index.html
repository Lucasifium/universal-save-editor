Where Half-Life 2 / Episode One / Episode Two keeps its saves

Folder: <Steam library>\steamapps\common\Half-Life 2\hl2\save (Episode One: episodic\save, Episode Two: ep2\save, Lost Coast: lostcoast\save)

Files: quick.sav, autosave.sav, half-life-001.sav …

You don't need to find it yourself: choose Select game in the editor, pick Half-Life 2 / Episode One / Episode Two, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Half-Life 2 / Episode One / Episode Two save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Half-Life 2 / Episode One / Episode Two and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
