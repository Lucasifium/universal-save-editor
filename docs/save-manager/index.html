Save manager for your game saves

Universal Save Editor keeps backups of your saves on your own computer. Make a named backup before a hard fight or a big choice, restore any backup in one click, or put a save aside to start a new game and come back to it later. It works for every game the editor opens, whether or not you edit anything.

What it does

  • Automatic backups. Every time the editor saves a file, it first backs up the file as it was. The last 30 are kept, and you can change that number in Edit › Preferences.
  • Named backups. Backups › Back up now… makes a backup with a name you choose, such as "before the final boss". It's kept until you delete it.
  • Restore. The Save manager button in the toolbar (or Backups › Save manager…) lists every backup of the open save. Restore this backup puts it back, and the current file is backed up first, so a restore can be undone too.
  • Quick restore. Backups › Quick restore puts back a recent backup without opening the list.
  • Compare. See what changed between a backup and the current save, byte by byte or value by value.
  • Start a new game, keep the old one. Many games only have one save. Back up and start a new game… makes a named backup and then moves the current save out of the way, so the game starts fresh. Restore the backup whenever you want your old game back.
  • Save gone? Recent files offers Restore a backup… even when the save itself no longer exists.

Where the backups are kept

Next to each save, in a folder of its own: Save Editor Backups/<file name>/. The backups have a .sebak extension, so no game loads them or writes over them. If the save's folder can't be written to, they go to the editor's own folder instead. You can also choose another folder, such as a synced folder or another drive.

Why you can trust it with your saves

  • Every backup and every restore is written to a temporary file, flushed to disk, read back and compared before it replaces anything.
  • Nothing is replaced if the current save can't be read and backed up first, for example while a game holds it locked.
  • If the game or a cloud sync changes a save after you opened it, the editor stops and asks before writing.
  • Everything stays on your computer. Nothing is uploaded.

The save manager is part of the downloaded app for Windows and Linux. The browser version can edit saves but can't keep backups, so keep your own copy when you use it.
