Where Unreal Engine saves live

  • Windows: %LOCALAPPDATA%\<project>\Saved\SaveGames
  • Steam on Linux (Proton): …/compatdata/<app id>/pfx/drive_c/users/steamuser/AppData/Local/<project>/Saved/SaveGames
  • Some games: Steam\userdata\<account>\<app id>\remote

What an Unreal Engine save is

When an Unreal Engine game saves with the engine's standard SaveGame system, it writes a .sav file that starts with the letters GVAS. Inside are the game's own variables, each with a name, a type and a value: whole numbers, decimals, true/false flags, text, lists and structures. The names are the ones the game's developers gave their variables, so a coin counter might be called Coins, Money or Currency, and a level PlayerLevel.

Finding the folder

The folder is named after the game's internal project name, which is not always the name on the box. Look in %LOCALAPPDATA% for a folder with a Saved\SaveGames folder inside it. The editor's Find my game's saves does this for the games it knows.

What can be changed

  • Numbers and text. Whole numbers, decimals and names are changed in place. The editor also fixes the size fields the format keeps for each property, so the file stays consistent when text gets longer or shorter.
  • True/false flags. They open as ticks.
  • Lists and maps. Saves written by Unreal Engine 5.4 and newer describe their lists, sets and maps fully, so the entries are shown one by one. Older saves show them as data that cannot be edited yet.
  • Whatever the editor doesn't understand is shown read-only, and left exactly as it was.

How to find the value you want

  1. Use the filter box with words like coin, money, gold, xp, level, health or stamina.
  2. Not sure which value it is? Save in the game, note the number you want to change, spend or gain some of it, save again, and use Tools › Compare with another save. It lists exactly what changed.
  3. Many games keep the character in one file and the world in another; the one with the number you saw in the game is the one to open.

Games that wrap the file

Some games compress or encrypt the file around the GVAS data, or add a checksum (Palworld, Ace Combat 8, Stellar Blade and others). For those the editor removes the wrapper, and puts it back and writes the checksum again on save. For an unknown wrapper, the file opens as raw data with value search instead.

Things to know

  • Close the game first, and keep the automatic backup until you've tried the edit in the game.
  • Games sometimes keep a second copy of a value (a number for the menu, a number for the world). If one doesn't stick, look for another with a similar name.
  • Don't edit saves of online or multiplayer modes.

How to edit a Unreal Engine save

  1. Download Universal Save Editor for Windows, macOS or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Find my game's saves and pick your game, or open the file yourself (or drag it onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Questions about Unreal Engine saves

Which Unreal Engine games does it work with?

Any game that saves with the engine's SaveGame system opens as a list of named values. Games with a screen of their own are marked in the game list; the others open in the values editor with a filter and value search.

How do I know a save is an Unreal Engine save?

The first four letters of the file are GVAS, and the file ends in .sav inside a Saved\SaveGames folder. The editor recognizes it by itself when you open it.

Why doesn't my edit show up in the game?

Some games keep a second copy of the value, or read it from the cloud save. Close the game, check that the file you edited is the one the game loads, and try a similarly named value.

Is it safe to use with online play?

Edited saves are for single-player play. Don't use them in online or multiplayer modes, where they can break rules or get an account flagged.

Does it cost anything?

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (Backups › Open save manager).
  • Works on games it doesn't know. Value search finds a number you know, or one you don't (a health bar, a hidden counter): scan, play, save, then keep what increased, decreased, changed or stayed the same.
  • Linux and Steam Deck. Find my game's saves also looks inside Proton and Wine prefixes, where Windows games run through Steam Play keep their saves.
  • In your language. Menus and messages in English, German, Spanish, French, Italian, Polish, Turkish, Russian, Brazilian Portuguese, Japanese, Korean, Simplified Chinese and Traditional Chinese, following the system language.
  • Save manager (toolbar button). Automatic and named backups kept in a folder next to each save, where no game loads them. Restore any backup (the current save is backed up first), compare it, or back up and start a new game on a one-save game and restore the old one later. Every backup is flushed to disk and checked before anything is replaced.
  • Open source. Anyone can read the code (GPL-3.0).
