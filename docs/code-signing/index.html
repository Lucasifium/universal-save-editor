Code signing policy

How the Windows downloads of Universal Save Editor are built and signed.

Every download on the Releases page is built by GitHub Actions from the source code in the public repository, by the release workflow kept in that repository. Nothing is built or uploaded by hand. Each release lists a SHA256SUMS.txt so a download can be checked against what the workflow produced.

The project has applied to SignPath Foundation for free code signing of its Windows programs. Once accepted, every Windows release is signed by SignPath after the workflow builds it, and only after a person on the team approves that release. Until then the Windows downloads are not signed.

Team roles

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. It edits save files on your own computer and makes no network connections of its own; the Help menu only opens web pages in your browser when you choose to.

Universal Save Editor is free, and always will be. Open source under the GPL-3.0. Not affiliated with any game developer or publisher; game names and trademarks belong to their owners. Always keep a backup of your saves. Code signing policy.
