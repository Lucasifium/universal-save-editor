What you can edit

Name, class and level; currency; attribute bars (level follows); HP / FP / Stamina meters; runes or souls to the next level (Elden Ring, Dark Souls III and I); inventory grids (with a search box across every list) for items, key items, storage, weapons (level and affinity / infusion), armor and talismans / rings; a Max upgrade materials button (Elden Ring: every Smithing Stone, Somber Smithing Stone and Glovewort to 999; Dark Souls: every titanite to 99); Elden Ring also has a Max crafting materials button that fills the cookbook materials you carry or store (meat, bones, flowers, mushrooms, butterflies, stones…) to 999, leaving key items alone

Where Dark Souls III keeps its saves

Folder: %APPDATA%\DarkSoulsIII\<Steam id>

Files: DS30000.sl2

You don't need to find it yourself: choose Select game in the editor, pick Dark Souls III, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Dark Souls III save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Dark Souls III and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Works on games it doesn't know. Value search finds a number you know, or one you don't (a health bar, a hidden counter): scan, play, save, then keep what increased, decreased, changed or stayed the same.
  • Linux and Steam Deck. Select game also looks inside Proton and Wine prefixes, where Windows games run through Steam Play keep their saves.
  • Xbox app and PC Game Pass. Saves hidden in the Xbox app's container are listed under the names the game gave them and open with the same screens as the Steam saves.
  • Unity PlayerPrefs. Coins and unlocks that Unity games keep in the Windows registry (or prefs files on Linux and macOS) open by name and are written back on save.
  • Flash and Haxe saves. Flash and AIR .sol files and the Haxe saves of OpenFL and HaxeFlixel games (Friday Night Funkin' among them) open with every value by name.
  • Emulator memory cards. PlayStation and PlayStation 2 memory card images open one save at a time and are written back into the card, with the PS2 card's error-correction codes made again.
  • Checksum finder. For a save it doesn't know, the editor looks for a CRC, sum or hash near the start or end of the file and writes it again every time you save.
  • Steam account switch. Finds the Steam IDs inside a save and changes them to another account, for saves copied between accounts or co-op hosts.
  • Command line too. info, list, get, set, decode and encode work from scripts, with the same checks and backups as the window.
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
