Éditeur de sauvegardes de Terraria character

Modifiez votre sauvegarde de Terraria character sur votre propre PC avec Universal Save Editor, un éditeur et gestionnaire de sauvegardes gratuit et hors ligne pour 590+ (593) jeux. Copiez, restaurez et commencez de nouvelles parties depuis la même fenêtre. Rien n'est envoyé en ligne et il n'y a aucune limite.

Ce que vous pouvez modifier

  • Life and mana
  • Permanent upgrades
  • Inventory, coins and ammo, equipment (armor, vanity, dyes, pets) and storage (piggy bank, safe, forge, void vault) as item grids
  • A Max crafting materials button (1.4.4 and later) that fills the ores, bars, gems, woods, monster drops and other materials you already have to 9999, leaving critters, fish and boss summons alone

L'éditeur affiche ces noms de valeurs en anglais.

Où Terraria character range ses sauvegardes

Dossier : Documents\My Games\Terraria\Players

Fichiers : <character>.plr

Pas besoin de le chercher vous-même : dans l'éditeur, choisissez Trouver les sauvegardes de mon jeu, sélectionnez Terraria character, et il liste les sauvegardes trouvées. (La version navigateur ne peut pas parcourir vos dossiers : ouvrez vous-même le fichier depuis ce dossier.)

Comment modifier votre sauvegarde de Terraria character

  1. Téléchargez Universal Save Editor pour Windows, macOS ou Linux et lancez-le simplement. Vous préférez ne rien installer ? Utilisez-le dans le navigateur : il s'exécute aussi sur votre ordinateur, et l'enregistrement télécharge le fichier modifié (Chrome et Edge peuvent enregistrer dans le même fichier).
  2. Fermez le jeu pour qu'il n'écrase pas vos modifications.
  3. Choisissez Trouver les sauvegardes de mon jeu, sélectionnez Terraria character et ouvrez votre sauvegarde (ou faites glisser le fichier de sauvegarde sur la fenêtre).
  4. Modifiez ce que vous voulez, puis choisissez Enregistrer. L'éditeur vérifie le nouveau fichier et copie d'abord l'ancien.

Questions sur les sauvegardes de Terraria character

Où se trouve le fichier de sauvegarde de Terraria character ?

En général dans Documents\My Games\Terraria\Players, dans des fichiers nommés <character>.plr. L'éditeur téléchargé le trouve pour vous : choisissez Trouver les sauvegardes de mon jeu et sélectionnez Terraria character.

Terraria character chargera-t-il toujours une sauvegarde modifiée ?

L'éditeur réécrit la sauvegarde dans le même format que celui du jeu et relit le nouveau fichier pour le vérifier avant de remplacer quoi que ce soit. L'original est copié d'abord ; si quelque chose paraît anormal dans le jeu, restaurez-le depuis Copies de secours.

Puis-je modifier les sauvegardes de Terraria character sur Steam Deck ou sous Linux ?

Oui. Il existe une version Linux, et Trouver les sauvegardes de mon jeu cherche aussi dans les préfixes Proton et Wine, où Steam Play range les sauvegardes des jeux Windows.

Puis-je modifier ma sauvegarde de Terraria character dans le navigateur ?

Oui. La version navigateur s'exécute sur votre propre ordinateur et n'envoie jamais la sauvegarde. Ouvrez le fichier vous-même et gardez-en une copie, car l'enregistrement télécharge le fichier modifié au lieu de copier l'ancien. Dans Chrome et Edge, elle peut aussi enregistrer dans le même fichier, en gardant d'abord l'original dans le navigateur.

Est-ce sans risque pour le jeu en ligne ?

Les sauvegardes modifiées sont réservées au jeu solo. Ne les utilisez pas dans les modes en ligne ou multijoueur, où elles peuvent enfreindre les règles ou faire signaler un compte.

Est-ce payant ?

Non. C'est gratuit et ça le restera : pas de publicité, pas de compte, pas de limites. Le code est open source sous licence GPL-3.0.

Pourquoi l'utiliser

  • Gratuit pour toujours. Pas de prix, pas de publicité, pas de compte, pas d'offre payante.
  • Hors ligne. Votre sauvegarde ne quitte jamais votre ordinateur : rien n'est envoyé, donc pas de limite de taille de fichier, de file d'attente ni de quota.
  • Sûr. Chaque sauvegarde est vérifiée en la relisant avant d'être écrite, et l'ancien fichier est d'abord copié (Copies de secours › Ouvrir le gestionnaire de sauvegardes).
  • Fonctionne avec les jeux qu'il ne connaît pas. La recherche de valeur trouve un nombre que vous connaissez, ou un que vous ne connaissez pas (une barre de vie, un compteur caché) : scannez, jouez, enregistrez, puis gardez ce qui a augmenté, diminué, changé ou n'a pas bougé.
  • Linux et Steam Deck. Trouver les sauvegardes de mon jeu cherche aussi dans les préfixes Proton et Wine, où les jeux Windows lancés via Steam Play gardent leurs sauvegardes.
  • Dans votre langue. Menus et messages en anglais, allemand, espagnol, français, italien, polonais, turc, russe, portugais du Brésil, japonais, coréen, chinois simplifié et chinois traditionnel, selon la langue du système.
  • Gestionnaire de sauvegardes (bouton de la barre d'outils). Copies automatiques et nommées gardées dans un dossier à côté de chaque sauvegarde, où aucun jeu ne les charge. Restaurez n'importe quelle copie (la sauvegarde actuelle est d'abord copiée), comparez-la, ou faites une copie et commencez une nouvelle partie dans un jeu à une seule sauvegarde, puis restaurez l'ancienne plus tard. Chaque copie est écrite sur le disque et vérifiée avant de remplacer quoi que ce soit.
  • Open source. N'importe qui peut lire le code (GPL-3.0).
