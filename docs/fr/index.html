Éditeur de sauvegardes gratuit et hors ligne pour 590+ (593) jeux

Universal Save Editor est un éditeur et un gestionnaire de sauvegardes pour les jeux PC. Ouvrez un fichier de sauvegarde, modifiez l'argent, les niveaux, les objets et les statistiques, puis enregistrez-le. Il fonctionne sur votre propre ordinateur : pas d'envoi en ligne, pas de compte, pas de limites, et l'application téléchargée copie chaque sauvegarde avant de la modifier. Il est gratuit, et le restera.

Gestionnaire de sauvegardes intégré

À chaque enregistrement, l'éditeur copie d'abord le fichier, automatiquement. Faites une copie nommée avant un boss ou un choix important, restaurez n'importe quelle copie en un clic, comparez-en deux, ou mettez une sauvegarde de côté pour commencer une nouvelle partie et y revenir plus tard. Les copies restent à côté de vos sauvegardes, sur votre ordinateur.

Comment fonctionne le gestionnaire de sauvegardes
Vous ne voulez pas exécuter de programme ? La version navigateur est le même éditeur, qui tourne dans la page web sur votre propre ordinateur : votre sauvegarde n'est jamais envoyée. Elle ne peut ni chercher des sauvegardes dans vos dossiers ni en faire des copies, donc ouvrez le fichier vous-même et gardez-en une copie ; l'enregistrement télécharge le fichier modifié (Chrome et Edge peuvent aussi enregistrer dans le même fichier, en gardant d'abord l'original dans le navigateur). Après la première visite, elle s'ouvre aussi sans connexion.

Qu'est-ce qu'un éditeur de sauvegardes ?

Un éditeur de sauvegardes ouvre le fichier qu'un jeu écrit quand vous enregistrez et vous permet de modifier son contenu : argent, expérience, objets, statistiques, déblocages. Les jeux utilisent de nombreux formats, souvent compressés, chiffrés ou protégés par une somme de contrôle, et chacun demande donc un traitement particulier. Universal Save Editor s'en charge pour 590+ (593) jeux dans un seul programme et réécrit le fichier comme le jeu l'attend.

Comment modifier un fichier de sauvegarde

  1. Téléchargez l'éditeur ou ouvrez la version navigateur.
  2. Dans l'application téléchargée, choisissez Trouver les sauvegardes de mon jeu et sélectionnez votre jeu. Dans le navigateur, ouvrez vous-même le fichier de sauvegarde.
  3. Modifiez ce que vous voulez. 523 jeux s'ouvrent sur un écran conçu pour eux, avec chaque valeur nommée ; les autres sauvegardes s'ouvrent sous forme de liste de valeurs, ou avec la recherche de valeur.
  4. Enregistrez. L'application téléchargée copie d'abord l'ancien fichier et relit le nouveau pour le vérifier avant de remplacer quoi que ce soit ; la version navigateur télécharge le fichier modifié (dans Chrome et Edge, elle peut aussi l'écrire dans le même fichier), donc gardez une copie de l'original. Chargez ensuite la sauvegarde dans votre jeu.

Pourquoi télécharger un éditeur de sauvegardes ?

  • Gratuit pour toujours. Pas de prix, pas de publicité, pas de compte, pas d'offre payante.
  • Hors ligne. Votre sauvegarde ne quitte jamais votre ordinateur : rien n'est envoyé, donc pas de limite de taille de fichier, de file d'attente ni de quota.
  • Sûr. Chaque sauvegarde est vérifiée en la relisant avant d'être écrite, et l'ancien fichier est d'abord copié (Copies de secours › Ouvrir le gestionnaire de sauvegardes).
  • Fonctionne avec les jeux qu'il ne connaît pas. La recherche de valeur trouve un nombre que vous connaissez, ou un que vous ne connaissez pas (une barre de vie, un compteur caché) : scannez, jouez, enregistrez, puis gardez ce qui a augmenté, diminué, changé ou n'a pas bougé.
  • Linux et Steam Deck. Trouver les sauvegardes de mon jeu cherche aussi dans les préfixes Proton et Wine, où les jeux Windows lancés via Steam Play gardent leurs sauvegardes.
  • Dans votre langue. Menus et messages en anglais, allemand, espagnol, français, italien, polonais, turc, russe, portugais du Brésil, japonais, coréen, chinois simplifié et chinois traditionnel, selon la langue du système.
  • Gestionnaire de sauvegardes (bouton de la barre d'outils). Copies automatiques et nommées gardées dans un dossier à côté de chaque sauvegarde, où aucun jeu ne les charge. Restaurez n'importe quelle copie (la sauvegarde actuelle est d'abord copiée), comparez-la, ou faites une copie et commencez une nouvelle partie dans un jeu à une seule sauvegarde, puis restaurez l'ancienne plus tard. Chaque copie est écrite sur le disque et vérifiée avant de remplacer quoi que ce soit.
  • Open source. N'importe qui peut lire le code (GPL-3.0).

Questions sur la modification des sauvegardes

Est-il sûr de modifier une sauvegarde ?

L'application téléchargée copie l'ancien fichier avant chaque enregistrement, puis relit le nouveau fichier et le vérifie avant de remplacer quoi que ce soit. Si le jeu n'accepte pas une modification, restaurez la copie depuis Copies de secours. Dans la version navigateur, gardez vous-même une copie de l'original (dans Chrome et Edge, Ouvrir pour enregistrer sur place en garde aussi une dans le navigateur avant le premier enregistrement).

Dois-je envoyer ma sauvegarde en ligne ?

Non. L'éditeur est un programme qui tourne sur votre ordinateur, sans connexion. La version navigateur s'exécute elle aussi sur votre ordinateur, dans la page, et n'envoie jamais la sauvegarde.

Avec quels jeux fonctionne-t-il ?

590+ (593) jeux figurent sur la page d'accueil en anglais, chacun avec une page indiquant ce qui peut être modifié et où se trouvent ses sauvegardes. Les sauvegardes de jeux non listés s'ouvrent souvent aussi : en valeurs nommées quand le format est courant, ou avec la recherche de valeur.

Fonctionne-t-il sur Steam Deck, Linux et Mac ?

Oui. Il existe des téléchargements pour Windows, Linux et macOS. Sous Linux et sur le Steam Deck, Trouver les sauvegardes de mon jeu cherche aussi dans les préfixes Proton et Wine, où Steam Play range les sauvegardes des jeux Windows.

Puis-je utiliser des sauvegardes modifiées en ligne ?

Les sauvegardes modifiées sont réservées au jeu solo. Ne les utilisez pas dans les modes en ligne ou multijoueur, où elles peuvent enfreindre les règles ou faire signaler un compte.

Est-ce payant ?

Non. C'est gratuit et ça le restera : pas de publicité, pas de compte, pas de limites. Le code est open source sous licence GPL-3.0.
