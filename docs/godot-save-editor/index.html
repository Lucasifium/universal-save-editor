Where Godot saves live

  • Windows: %APPDATA%\Godot\app_userdata\<project>
  • Linux: ~/.local/share/godot/app_userdata/<project>
  • macOS: ~/Library/Application Support/Godot/app_userdata/<project>

Finding the folder

A Godot game saves to the user:// folder. On Windows it is %APPDATA%\Godot\app_userdata\<project name>; Linux and macOS are in the list above. Some games choose their own folder name instead, which is then right beside it under %APPDATA%. The folder holds whatever files the game's developer wrote, so look at the names and the dates to find the one that changes when you save.

The formats

  • JSON (.json, and often .save or .dat files that hold text). The most common choice. Opens as a tree of named values.
  • Config files (.cfg, .ini), Godot's ConfigFile format with [sections] and key=value lines. Opens as sections of named values.
  • Binary Variant files written with store_var in Godot 4. Opens as a typed tree (numbers, text, lists, dictionaries, vectors). The editor only accepts a file if writing it back unchanged would reproduce it byte for byte; a file that uses a type it doesn't know opens as raw data instead of risking a bad save.
  • Password-protected files (open_encrypted_with_pass). They need the game's password: use Tools › Decrypt with password, and the file is encrypted again with the same password on save. The editor cannot guess a password; some games publish theirs, or their community does.
  • Resource files (.tres, .res, .scn) are not decoded: they open as text or as raw data, where value search finds a number you know.

What can be changed

Numbers, text and true/false values in whatever the file holds: coins, health, experience, unlocked levels, settings. A game with a screen of its own in the editor (for example Luck be a Landlord) shows its values under familiar names.

Things to know

  • Close the game before you edit, and keep the backup the editor makes.
  • Godot stores whole numbers and decimals as different types, and a game that expects a whole number can fail on a decimal. The editor keeps the type the file had.
  • A game's exported data (.pck files) is not a save and isn't touched. Settings that the game keeps in project.godot are not saves either.
  • Games made with Godot 3 may use a different binary layout. JSON, config and text saves open the same in both.

How to edit a Godot save

  1. Download Universal Save Editor for Windows, macOS or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Find my game's saves and pick your game, or open the file yourself (or drag it onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Questions about Godot saves

How do I find a Godot game's save folder?

Open %APPDATA%\Godot\app_userdata (Windows) and look for the folder named after the game. If it isn't there, the game uses its own folder name directly under %APPDATA%. The editor's Find my game's saves lists these for the games it knows.

My Godot save is unreadable. What now?

If it looks like random bytes, the game probably encrypts it with a password. Use Tools › Decrypt with password if you have the password; without it the file can't be opened. A text file that starts with { is JSON and opens normally.

Is it safe for the game's save?

The editor writes the file back in the same format, checks it by reading it again, and backs up the old one first. A Godot file it cannot reproduce exactly is shown as raw data instead of being rewritten.

Is it safe to use with online play?

Edited saves are for single-player play. Don't use them in online or multiplayer modes, where they can break rules or get an account flagged.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (Backups › Open save manager).
  • Works on games it doesn't know. Value search finds a number you know, or one you don't (a health bar, a hidden counter): scan, play, save, then keep what increased, decreased, changed or stayed the same.
  • Linux and Steam Deck. Find my game's saves also looks inside Proton and Wine prefixes, where Windows games run through Steam Play keep their saves.
  • In your language. Menus and messages in English, German, Spanish, French, Italian, Polish, Turkish, Russian, Brazilian Portuguese, Japanese, Korean, Simplified Chinese and Traditional Chinese, following the system language.
  • Save manager (toolbar button). Automatic and named backups kept in a folder next to each save, where no game loads them. Restore any backup (the current save is backed up first), compare it, or back up and start a new game on a one-save game and restore the old one later. Every backup is flushed to disk and checked before anything is replaced.
  • Open source. Anyone can read the code (GPL-3.0).
