What you can edit

Life and mana; permanent upgrades; inventory, coins and ammo, equipment (armor, vanity, dyes, pets) and storage (piggy bank, safe, forge, void vault) as item grids; a Max crafting materials button (1.4.4 and later) that fills the ores, bars, gems, woods, monster drops and other materials you already have to 9999, leaving critters, fish and boss summons alone

Where Terraria (characters) keeps its saves

Folder: Documents\My Games\Terraria\Players

Files: <character>.plr

You don't need to find it yourself: choose Select game in the editor, pick Terraria (characters), and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Terraria (characters) save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Terraria (characters) and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
