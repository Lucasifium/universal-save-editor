The Sims 4 save editor

Edit your The Sims 4 save on your own PC with Universal Save Editor, a free, offline save editor and manager for 520+ (520) games. Back up, restore and start new runs from the same window. Nothing is uploaded and there are no limits.

What you can edit

One tab per household: funds (up to 99,999,999) and its Sims with their names, ages and genders. Open Slot_0000000N.save; the game data is stored uncompressed when saved, so the file grows (checked on a public save, not yet tried in the game). Skills and traits aren't mapped yet

Where The Sims 4 keeps its saves

Folder: Documents\Electronic Arts\The Sims 4\saves

Files: Slot_00000001.save … (and .save.ver0 backups)

You don't need to find it yourself: choose Find my game's saves in the editor, pick The Sims 4, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your The Sims 4 save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Find my game's saves, pick The Sims 4 and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (Backups › Open save manager).
  • Works on games it doesn't know. Value search finds a number you know, or one you don't (a health bar, a hidden counter): scan, play, save, then keep what increased, decreased, changed or stayed the same.
  • Linux and Steam Deck. Find my game's saves also looks inside Proton and Wine prefixes, where Windows games run through Steam Play keep their saves.
  • Xbox app and PC Game Pass. Saves hidden in the Xbox app's container are listed under the names the game gave them and open with the same screens as the Steam saves.
  • Unity PlayerPrefs. Coins and unlocks that Unity games keep in the Windows registry (or prefs files on Linux and macOS) open by name and are written back on save.
  • Flash and Haxe saves. Flash and AIR .sol files and the Haxe saves of OpenFL and HaxeFlixel games (Friday Night Funkin' among them) open with every value by name.
  • Emulator memory cards. PlayStation and PlayStation 2 memory card images open one save at a time and are written back into the card, with the PS2 card's error-correction codes made again. Single saves exported by cheat devices and PC tools (.mcs, .psu, .max, .cbs, .xps and PS3 .psv) open too and are packed back in their own format.
  • Checksum finder. For a save it doesn't know, the editor looks for a CRC, sum or hash near the start or end of the file and writes it again every time you save.
  • Find a value, step by step. On a game it doesn't know, a short guide walks you through finding a number and changing it, and the search can refine by itself each time the game saves.
  • Your own templates. Name the values you found and press Use for every save, or write a small JSON file saying where each value is; matching saves then open as a list of those values, with the checksum kept right. Names and templates are easy to share.
  • Bulk edit and presets. Tick many values and set, add to or multiply them all at once; keep a set of changes as a preset and make it again on another save or slot.
  • Console cheat patches. About 2,400 PlayStation 1 to 4, PSP, Vita and Dreamcast games have ready-made cheats from the Apollo patch collection built in: pick the codes and apply them. Encrypted saves from about 80 PS3, PS4, PSP and Vita games open already decrypted, and are encrypted again on save.
  • Dreamcast saves. VMU .vms files and Nexus .dci files open with their header CRC and byte order handled, and are written back the same way.
  • Sega Saturn saves. Single .bup, .sro, .xml, .b64 and .cms saves, and whole backup RAM images from Mednafen, Beetle, Yabause, Kronos and SAROO, one save at a time.
  • In your language. Menus and messages in English, German, Spanish, French, Brazilian Portuguese, Japanese and Simplified Chinese, following the system language.
  • Several saves in tabs. Open more than one save at a time and copy a value, or a whole group such as an inventory, from one save to another.
  • Steam account switch. Finds the Steam IDs inside a save and changes them to another account, for saves copied between accounts or co-op hosts.
  • Finds your games. The start page lists the games whose saves are on this computer, newest first, one click from the latest save; Find my game's saves shows them first, with a badge for how much of each game can be edited.
  • Never writes over a newer save. If the game or a cloud sync saved the file after you opened it, saving stops and asks (reload, or save anyway with the newer file backed up first).
  • Japanese, Chinese and Korean names. Shown with your computer's own fonts in the downloaded app.
  • Save manager (Backups menu). Automatic and named backups kept in a folder next to each save, where no game loads them. Restore any backup (the current save is backed up first), compare it, or back up and start a new game on a one-save game and restore the old one later. Every backup is flushed to disk and checked before anything is replaced.
  • Command line too. info, list, get, set, decode and encode work from scripts, with the same checks and backups as the window.
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
