Roguelike, roguelite and idle save editors

Universal Save Editor opens the saves of 33 roguelikes, roguelites, deckbuilders and idle games, where unlocks and meta currency carry between runs. Pick your game to see what it can change and where its saves are. It's free, works offline and backs up every save before changing it.
