What you can edit

Bottle caps, experience, karma, S.P.E.C.I.A.L. and the points added to each skill (checked on real saves, not yet tried in the game)

Where Fallout: New Vegas keeps its saves

Folder: Documents\My Games\FalloutNV\Saves

Files: *.fos

You don't need to find it yourself: choose Select game in the editor, pick Fallout: New Vegas, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Fallout: New Vegas save

  1. Download Universal Save Editor for Windows, Linux or Android. On Windows and Linux just run it; on Android install the APK. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Fallout: New Vegas and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
