What you can edit

Party: gil, and every character's and aeon's HP, MP, maxima and stats (with and without equipment), AP, Sphere levels, overdrive gauge and mode. Abilities: every skill, special, white and black magic per character and aeon, with a learn-all button. Overdrives: each character's overdrives and overdrive modes. Items: all 112 item slots (item and count, with a set-all-to-99 button) and the key items. Monster Arena: how many of each fiend is captured. The checksum (the game's own CRC-16) is updated

Where Final Fantasy X / X-2 HD Remaster keeps its saves

Folder: Documents\SQUARE ENIX\FINAL FANTASY X&X-2 HD Remaster

Files: ffx_###

You don't need to find it yourself: choose Select game in the editor, pick Final Fantasy X / X-2 HD Remaster, and it lists the saves it finds. (The browser version can't look through your folders: open the file from this folder yourself.)

How to edit your Final Fantasy X / X-2 HD Remaster save

  1. Download Universal Save Editor for Windows or Linux; just run it. Rather not install anything? Use it in your browser instead: it runs on your computer too, and saving downloads the edited file.
  2. Close the game, so it doesn't write over your changes.
  3. Choose Select game, pick Final Fantasy X / X-2 HD Remaster and open your save (or drag the save file onto the window).
  4. Change what you want, then Save. The editor checks the new file and backs up the old one first.

Why use it

  • Free, forever. No price, no ads, no account, no paid tier.
  • Offline. Your save never leaves your computer: nothing is uploaded, so there are no file size limits, queues or rate limits.
  • Safe. Every save is checked by reading it back before it's written, and the old file is backed up first (File › Restore previous version).
  • Works on games it doesn't know. Value search finds a number you know, or one you don't (a health bar, a hidden counter): scan, play, save, then keep what increased, decreased, changed or stayed the same.
  • Linux and Steam Deck. Select game also looks inside Proton and Wine prefixes, where Windows games run through Steam Play keep their saves.
  • Xbox app and PC Game Pass. Saves hidden in the Xbox app's container are listed under the names the game gave them and open with the same screens as the Steam saves.
  • Unity PlayerPrefs. Coins and unlocks that Unity games keep in the Windows registry (or prefs files on Linux and macOS) open by name and are written back on save.
  • Flash and Haxe saves. Flash and AIR .sol files and the Haxe saves of OpenFL and HaxeFlixel games (Friday Night Funkin' among them) open with every value by name.
  • Emulator memory cards. PlayStation and PlayStation 2 memory card images open one save at a time and are written back into the card, with the PS2 card's error-correction codes made again. Single saves exported by cheat devices and PC tools (.mcs, .psu, .max, .cbs, .xps and PS3 .psv) open too and are packed back in their own format.
  • Checksum finder. For a save it doesn't know, the editor looks for a CRC, sum or hash near the start or end of the file and writes it again every time you save.
  • Your own templates. For a game it doesn't know, write a small JSON file saying where each value is; matching saves then open as a list of those values, with the checksum kept right. Templates are easy to share.
  • Console cheat patches. About 2,400 PlayStation 1 to 4, PSP, Vita and Dreamcast games have ready-made cheats from the Apollo patch collection built in: pick the codes and apply them. Encrypted saves from about 80 PS3, PS4, PSP and Vita games open already decrypted, and are encrypted again on save.
  • Dreamcast saves. VMU .vms files and Nexus .dci files open with their header CRC and byte order handled, and are written back the same way.
  • Sega Saturn saves. Single .bup, .sro, .xml, .b64 and .cms saves, and whole backup RAM images from Mednafen, Beetle, Yabause, Kronos and SAROO, one save at a time.
  • Steam account switch. Finds the Steam IDs inside a save and changes them to another account, for saves copied between accounts or co-op hosts.
  • Command line too. info, list, get, set, decode and encode work from scripts, with the same checks and backups as the window.
  • Open source. Anyone can read the code (GPL-3.0).

Edited saves are for single-player play. Don't use them in online or multiplayer modes.
