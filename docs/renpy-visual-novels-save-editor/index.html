Ren'Py saves: a guide

Where the files are

  • Windows: %APPDATA%\RenPy\<game>-<number>
  • Linux: ~/.renpy/<game>-<number>
  • macOS: ~/Library/RenPy/<game>-<number>

Ren'Py is the engine behind most visual novels. Its saves look the same in every game, so one guide covers them all. Some games, and older versions of the engine, keep saves in a saves folder next to the game instead.

The files

  • 1-1-LT1.save, 1-2-LT1.save and so on: one file per save slot (page, slot). auto-1-LT1.save and quick-1-LT1.save are the automatic and quick saves.
  • persistent: what the game remembers between playthroughs, such as gallery unlocks, endings seen and settings. Its values are edited the same way.
  • A .save file is a zip archive holding the game's variables, a screenshot and a signature. The editor opens the archive for you, and puts it back together on save.

What the values mean

The editor lists the story's own variables: numbers (money, affection, stats), true/false flags (a route finished, a scene seen) and text (the player's name). Names come from the game's script, so they differ from game to game: use the filter box, and look for money, gold, love, points and route. The usual ones are shown first. The engine's own internals sit under a separate heading and are best left alone.

Signed saves (Ren'Py 8.1 and newer)

Newer versions of Ren'Py sign every save with a key kept on your computer (on Windows, %APPDATA%\RenPy\tokens\security_keys.txt). A save whose data no longer matches its signature makes the game ask whether to trust it, and may refuse it. On Windows, Universal Save Editor signs the edited save again with your own key, which is what the game does itself when it saves, so the game loads it normally. If the key isn't found, it leaves the signature out and the game asks once before loading the save. A persistent file that carries a signature is not saved without the key, because the game would throw it away.

Rollback

A Ren'Py save also keeps a short history of earlier values, for rolling back. On load the game steps back to the last choice using that history, which would undo an edit made only to the current value. The editor changes the earlier copies too, so the edit is still there after loading.

Things to know

  • Close the game before you edit, and load the edited slot from the game's own load screen.
  • Changing a number is safe; changing a true/false flag can skip or repeat a scene, so make a backup first (the editor does, automatically) and change one flag at a time.

Questions about Ren'Py visual novels saves

Where is the Ren'Py visual novels save file?

Usually in %APPDATA%\RenPy\<game>, in files named 1-1-LT1.save, persistent. The downloaded editor finds it for you: choose Find my game's saves and pick Ren'Py visual novels.

Will Ren'Py visual novels still load an edited save?

The editor writes the save back in the same format the game uses and reads the new file back to check it before replacing anything. The original is backed up first, so if anything looks wrong in the game, restore it from Backups.

Can I edit Ren'Py visual novels saves on Steam Deck or Linux?

Yes. There's a Linux build, and Find my game's saves also looks inside the Proton and Wine prefixes where Steam Play keeps Windows games' saves.

Can I edit my Ren'Py visual novels save in the browser?

Yes. The browser version runs on your own computer and never uploads the save. Open the file yourself and keep a copy, because saving downloads the edited file instead of backing up the old one. In Chrome and Edge it can also save back to the same file, keeping the original in the browser first.

Is it safe to use with online play?

Edited saves are for single-player play. Don't use them in online or multiplayer modes, where they can break rules or get an account flagged.

Does it cost anything?

No. It's free and always will be: no ads, no account and no limits. The code is open source under the GPL-3.0.
