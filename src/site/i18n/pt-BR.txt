Is it safe to edit a save file?
= É seguro editar um arquivo de save?

The downloaded app backs up the old file before every save, then reads the new file back and checks it before replacing anything. If the game doesn't like an edit, restore the backup from <em>Backups</em>. In the browser version, keep a copy of the original yourself (in Chrome and Edge, <em>Open to save in place</em> also keeps one in the browser before the first save).
= O app baixado faz um backup do arquivo antigo antes de cada gravação, depois lê o arquivo novo de volta e o confere antes de substituir qualquer coisa. Se o jogo não aceitar uma alteração, restaure o backup em <em>Backups</em>. Na versão para navegador, guarde você mesmo uma cópia do original (no Chrome e no Edge, <em>Abrir para salvar no próprio arquivo</em> também guarda uma cópia no navegador antes da primeira gravação).

What is a save editor?
= O que é um editor de saves?

A save editor opens the file a game writes when you save and lets you change what is stored in it: money, experience, items, stats, unlocks. Games keep their saves in many formats, often compressed, encrypted or guarded by a checksum, so each one needs its own handling. Universal Save Editor does that for {0}+ ({1}) games in one program and writes the file back the way the game expects it.
= Um editor de saves abre o arquivo que um jogo grava quando você salva e deixa você alterar o que está guardado nele: dinheiro, experiência, itens, atributos, desbloqueios. Os jogos guardam seus saves em muitos formatos, muitas vezes compactados, criptografados ou protegidos por uma soma de verificação, então cada um precisa de um tratamento próprio. O Universal Save Editor faz isso para {0}+ ({1}) jogos em um só programa e grava o arquivo de volta do jeito que o jogo espera.
