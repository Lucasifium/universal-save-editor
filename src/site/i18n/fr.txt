Is it safe to edit a save file?
= Est-il sûr de modifier une sauvegarde ?

The downloaded app backs up the old file before every save, then reads the new file back and checks it before replacing anything. If the game doesn't like an edit, restore the backup from <em>Backups</em>. In the browser version, keep a copy of the original yourself (in Chrome and Edge, <em>Open to save in place</em> also keeps one in the browser before the first save).
= L'application téléchargée copie l'ancien fichier avant chaque enregistrement, puis relit le nouveau fichier et le vérifie avant de remplacer quoi que ce soit. Si le jeu n'accepte pas une modification, restaurez la copie depuis <em>Copies de secours</em>. Dans la version navigateur, gardez vous-même une copie de l'original (dans Chrome et Edge, <em>Ouvrir pour enregistrer sur place</em> en garde aussi une dans le navigateur avant le premier enregistrement).

What is a save editor?
= Qu'est-ce qu'un éditeur de sauvegardes ?

A save editor opens the file a game writes when you save and lets you change what is stored in it: money, experience, items, stats, unlocks. Games keep their saves in many formats, often compressed, encrypted or guarded by a checksum, so each one needs its own handling. Universal Save Editor does that for {0}+ ({1}) games in one program and writes the file back the way the game expects it.
= Un éditeur de sauvegardes ouvre le fichier qu'un jeu écrit quand vous enregistrez et vous permet de modifier son contenu : argent, expérience, objets, statistiques, déblocages. Les jeux utilisent de nombreux formats, souvent compressés, chiffrés ou protégés par une somme de contrôle, et chacun demande donc un traitement particulier. Universal Save Editor s'en charge pour {0}+ ({1}) jeux dans un seul programme et réécrit le fichier comme le jeu l'attend.
