Is it safe to edit a save file?
= ¿Es seguro editar una partida?

The downloaded app backs up the old file before every save, then reads the new file back and checks it before replacing anything. If the game doesn't like an edit, restore the backup from <em>Backups</em>. In the browser version, keep a copy of the original yourself (in Chrome and Edge, <em>Open to save in place</em> also keeps one in the browser before the first save).
= La aplicación descargada hace una copia del archivo anterior antes de cada guardado, y después vuelve a leer el archivo nuevo y lo comprueba antes de reemplazar nada. Si al juego no le gusta un cambio, restaura la copia desde <em>Copias de seguridad</em>. En la versión para navegador, guarda tú mismo una copia del original (en Chrome y Edge, <em>Abrir para guardar en el mismo archivo</em> también guarda una en el navegador antes del primer guardado).

What is a save editor?
= ¿Qué es un editor de partidas?

A save editor opens the file a game writes when you save and lets you change what is stored in it: money, experience, items, stats, unlocks. Games keep their saves in many formats, often compressed, encrypted or guarded by a checksum, so each one needs its own handling. Universal Save Editor does that for {0}+ ({1}) games in one program and writes the file back the way the game expects it.
= Un editor de partidas abre el archivo que escribe un juego cuando guardas y te deja cambiar lo que contiene: dinero, experiencia, objetos, estadísticas, desbloqueos. Los juegos guardan en muchos formatos, a menudo comprimidos, cifrados o protegidos por una suma de comprobación, así que cada uno necesita su propio tratamiento. Universal Save Editor lo hace para {0}+ ({1}) juegos en un solo programa y vuelve a escribir el archivo como el juego lo espera.
