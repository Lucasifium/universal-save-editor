Is it safe to edit a save file?
= Ist es sicher, einen Spielstand zu bearbeiten?

The downloaded app backs up the old file before every save, then reads the new file back and checks it before replacing anything. If the game doesn't like an edit, restore the backup from <em>Backups</em>. In the browser version, keep a copy of the original yourself (in Chrome and Edge, <em>Open to save in place</em> also keeps one in the browser before the first save).
= Die heruntergeladene App sichert die alte Datei vor jedem Speichern, liest die neue Datei dann wieder ein und prüft sie, bevor etwas ersetzt wird. Gefällt dem Spiel eine Änderung nicht, stellst du die Sicherung unter <em>Sicherungen</em> wieder her. In der Browser-Version bewahrst du das Original selbst auf (in Chrome und Edge legt <em>Zum Speichern an Ort und Stelle öffnen</em> vor dem ersten Speichern zusätzlich eine Kopie im Browser ab).

What is a save editor?
= Was ist ein Spielstand-Editor?

A save editor opens the file a game writes when you save and lets you change what is stored in it: money, experience, items, stats, unlocks. Games keep their saves in many formats, often compressed, encrypted or guarded by a checksum, so each one needs its own handling. Universal Save Editor does that for {0}+ ({1}) games in one program and writes the file back the way the game expects it.
= Ein Spielstand-Editor öffnet die Datei, die ein Spiel beim Speichern schreibt, und lässt dich ändern, was darin steht: Geld, Erfahrung, Gegenstände, Werte, Freischaltungen. Spiele speichern in vielen Formaten, oft komprimiert, verschlüsselt oder durch eine Prüfsumme geschützt, daher braucht jedes seine eigene Behandlung. Universal Save Editor übernimmt das für {0}+ ({1}) Spiele in einem Programm und schreibt die Datei so zurück, wie das Spiel sie erwartet.
