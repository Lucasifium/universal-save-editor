What is a save editor?
= 什么是存档编辑器？

A save editor opens the file a game writes when you save and lets you change what is stored in it: money, experience, items, stats, unlocks. Games keep their saves in many formats, often compressed, encrypted or guarded by a checksum, so each one needs its own handling. Universal Save Editor does that for {0}+ ({1}) games in one program and writes the file back the way the game expects it.
= 存档编辑器会打开游戏保存时写出的文件，让你修改其中存储的内容：金钱、经验、物品、属性、解锁项。游戏的存档格式多种多样，往往经过压缩、加密或带有校验和保护，所以每款游戏都需要单独处理。Universal Save Editor 用一个程序为 {0}+（{1}）款游戏完成这些工作，并按游戏期望的方式把文件写回去。
